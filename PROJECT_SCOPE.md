# Project scope

## Goal
Show practical ITSM automation skills through a safe, reproducible prototype.

## Included
- Incident triage suggestions with transparent rationale
- Repeated incident pattern detection
- MIR drafting from selected incident data and user notes
- Sample synthetic data, tests, and CI workflow

## Not included in this version
- Live Remedy/ServiceNow integration
- Production incident policy enforcement
- Autonomous incident declaration
- AI-generated root-cause claims
- Authentication or multi-user data storage

## Acceptance checklist
- [ ] Install dependencies
- [ ] Launch Streamlit locally
- [ ] Confirm all three tabs work
- [ ] Generate and download a sample MIR
- [ ] Run tests successfully
- [ ] Review data for confidential information before publishing
